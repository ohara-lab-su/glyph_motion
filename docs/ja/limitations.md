# 制約と注意事項

## 中心線は筆順ではない

通常フォントから抽出した中心線のパス順は、スケルトングラフの追跡順です。人間の筆順や自然なペン運びを保証しません。筆順が重要な漢字書字にはKanjiVG経路を使用します。

## アルファベットは限定実装

内蔵single-lineアルファベットは、現時点で `A B C I L O T X Y Z` のみです。一般的な英数字フォント一式ではありません。

## KanjiVGデータが必要

漢字ストローク生成は、対応するSVGファイルが指定ディレクトリに存在することを前提とします。フォントファイルからKanjiVG相当の筆順を推定する機能はありません。

## 曲線は折れ線近似

フォント輪郭およびSVGベジェ曲線は、指定分割数に従う点列へ変換されます。分割数を増やすと形状近似は改善しますが、点数とロボット指令数が増加します。

## 実機書字前の確認

COBOTTA書字は実機を動作させます。座標軸、軸交換、符号、反転、書字面Z、ペン上げ高さ、作業空間、速度を実機環境に合わせて確認する必要があります。特に `robot_swap_xy`、`robot_x_sign`、`robot_y_sign` は設置方向に直接影響します。

## 文書化範囲

このPages一式は、今回提示されたフォント処理、KanjiVG、表示、COBOTTA writerの実装を根拠にしています。`font_geometry` と `font_line_layout` の完全な公開APIは今回の提示ファイルに含まれていないため、それらの内部フィールド全体はAPIリファレンス化していません。
